# NeuroLeads AI -- Sales Intelligence Orchestrator

Autonomous B2B sales intelligence pipeline: researches a company domain,
extracts structured facts, reasons about its biggest relevant weakness,
drafts a personalized outreach email, has it critiqued, and pauses for
human approval before marking it ready to send.

See CLAUDE.md for dev conventions and the project blueprint doc for the
full architecture, phase breakdown, and cost model.
